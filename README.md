# Moblo Home Practice

집에서 태블릿으로 모블로형 블록 순서와 방향 감각을 연습하는 개인용 웹앱 프로토타입입니다.

공식 모블로 에셋은 포함하지 않았고, 자체 제작한 블록 스타일과 미션으로 구성되어 있습니다.

## 실행

정적 웹앱이라 별도 빌드가 필요 없습니다.

- 로컬에서 `index.html`을 브라우저로 열기
- 또는 간단한 서버로 실행:

```bash
python -m http.server 5173
```

그 다음 `http://127.0.0.1:5173/index.html`로 접속합니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`: 태블릿 중심 UI 스타일
- `app.js`: 블록, 연령별 미션, 효과음, 실행 로직

## 현재 포함 기능

- 만 4세, 만 5세, 만 6세 난이도 탭
- 총 37개 미션
- 색 순서, 방향 전환, 멈춤, 반복, 장애물 회피, 디버깅 문제
- Web Audio 기반 효과음
- 자체 제작 그래픽 테마, 이채아(채아) 캐릭터, 성공 연출
- 브라우저 로컬 저장소 기반 진행 기록
